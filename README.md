# sheiks-and-bishops

This repo contains HTML markup that is responsible for the look and feel of www.sheiksandbishop.com.

> NB: Please do NOT make changes to pages found in the root folder. If you need to update any, please update it in the __pages__ folder.

## Requirements

- Yarn `v1.22.22` An NPM package manager used for dependency management.
- Node `v24.14.0`, [Node.js](https://nodejs.org) runtime requirement.
- Git
- Docker Desktop

## Setup | Getting Started

- Clone the repository `git clone git@github.com/aw-ng/sheiks-and-bishops.git`.
- Run `yarn start` to spin up an instance of the website server.
- Website should now be accessible at port 5577 using [http://localhost:5577](http://localhost:5577).

## Available Scripts

Compiles CSS.

```bash
yarn compile:css
```

Compile JS.

```bash
yarn compile:js
```

Runs both CSS and JavaScript compilation.

```bash
yarn build
```
